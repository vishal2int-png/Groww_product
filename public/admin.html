Update the key

Saving first checks the key with a live Gemini call, then writes it to the server’s .env and switches over without a restart.

This deployment’s environment variables are managed by the hosting platform, so the key can’t be written from here.

  1. Open the project in the Vercel dashboard → Settings → Environment Variables.
  2. Edit GEMINI_API_KEY (Production, and Preview if used) and save the new value.
  3. Go to Deployments → latest → Redeploy. The new key is live when the deploy finishes.

Or with the Vercel CLI:

vercel env rm GEMINI_API_KEY production
vercel env add GEMINI_API_KEY production
vercel --prod

Then use “Test current key” above to confirm.
